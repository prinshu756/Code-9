# **App Name**: Network

## Core Features:

- Link Display: Display links in a visually appealing and organized manner.
- Save Links: Allow users to save their links.
- Load Links: Allow users to load previously saved links.
- Link Suggestion: AI tool to suggest relevant links based on user's current saved links.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke trust and connection.
- Background color: Light, desaturated blue (#E3F2FD) for a clean, airy feel.
- Accent color: A slightly brighter blue (#2196F3) for interactive elements.
- Font pairing: 'Poppins' (sans-serif) for headings and 'PT Sans' (sans-serif) for body text.
- Use simple, line-based icons to represent different link types.
- Clean, card-based layout for displaying links, focusing on readability and easy navigation.
- Subtle animations for link interactions, like hover effects and loading indicators.
